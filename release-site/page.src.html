자잘한 고침

끝난 대화에 보내면 자동 재개 · 한글 반쪽 깨짐 · Codex 기록 짝짓기 · 기록 파일 크기 제한.

서명과 개인정보무엇으로 진짜인지 확인하고, 무엇이 밖으로 나가는지

업데이트 서명 — 고도화판 업데이트는 자체 서명(Ed25519)과 지문(SHA-256)이 모두 맞는 파일만 설치해요. 윈도 게시자 서명은 아직 없어요 — 그래서 처음 설치할 때 윈도가 경고를 보일 수 있어요. 릴리스에 함께 올린 .sha256 지문으로 받은 파일을 확인할 수 있어요.
개인정보 — IRIS는 대화와 파일을 만든 이에게 보내지 않아요. 요청 내용은 고른 AI 회사(Anthropic · OpenAI · Google)로 가고, 로컬 AI는 PC 안에서만 돌아요. 새 판 확인은 GitHub를 하루 한 번 봐요(설정에서 끌 수 있어요).

윈도의 스마트 앱 컨트롤이 인터넷에서 받은 실행 파일을 막는 거예요. 컴퓨터나 IRIS가 고장 난 것이 아니에요.

방법 ㉮ 차단 해제 (권장)

zip 오른쪽 클릭 → 속성 → 아래쪽 「차단 해제」 체크 → 확인. 풀어 둔 폴더는 지우고 zip을 다시 푼 뒤 IRIS-설치.cmd 를 눌러요.

방법 ㉯ 주소창에서 실행

zip을 푼 폴더의 탐색기 주소창을 누르고 cmd /c IRIS-설치.cmd 를 쳐 넣은 뒤 Enter.

그래도 안 되면

탐색기 주소창에 %LOCALAPPDATA%\IRIS-Installer 를 넣으면 설치 기록(bootstrap.log)이 있는 폴더가 열려요. 도움을 청할 때 함께 보내 주세요.
